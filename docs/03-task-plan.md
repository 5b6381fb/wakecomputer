## 4. 完成定义（DoD）

每个任务合并前必须满足：

- [ ] 代码通过 `gofmt` / `ktlint` / `detekt` / `golangci-lint`
- [ ] 新增逻辑有单测；修改 API 有集成测试
- [ ] 错误路径有明确错误码与用户可读文案
- [ ] 日志无敏感字段；新增外部输入有校验
- [ ] 文档（README / API / 部署）同步更新
- [ ] PR 自测记录（截图或 curl 输出）附在描述中

v1.0 发布门槛：

- [ ] 需求文档 §8 的 AC-01 ~ AC-12 全部通过
- [ ] 无 P0/P1 未关闭缺陷
- [ ] 服务端镜像 ≤ 40 MB、RSS ≤ 80 MB、空闲 CPU < 1%
- [ ] APK ≤ 12 MB，Android 8/12/15/16 实机或模拟器通过
- [ ] 未授权访问矩阵 100% 返回 401/403
- [ ] 现有 sub2api / PostgreSQL / Redis 容器与数据卷零变化
- [ ] 备份恢复与版本回滚各演练一次

```bash
cd /opt/wakecomputer
cp -a data data.bak.$(date +%F)

docker compose up -d
docker compose logs --tail=100 wakecomputer
curl -fsS http://192.168.1.2:8085/healthz
```

- [ ] 登录 / 列表 / 唤醒 / 关机各 1 次
